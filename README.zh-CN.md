# Perk Done

[English](README.md) · **简体中文**

用 Chrome 扩展整理信用卡权益。添加卡片、标记完成，查看本季度还有哪些权益待使用，无需另外注册账号或连接银行。

**TypeScript · React · Manifest V3 · Chrome Sync · [MIT 许可证](LICENSE)**

![Perk Done 深色面板](docs/screenshots/dashboard-dark.png)

[查看小窗口](docs/screenshots/popup-dark.png)

## 功能

- **年度时间表。** 月度、季度、半年度和全年权益共用同一条 12 个月时间轴，可查看全部卡片或勾选部分卡片。
- **一键完成。** 点击权益即可用当天日期标记完成，再次点击可修改日期或撤销完成。
- **金额进度。** 在小输入框中填写累计使用金额，显示剩余额度；记满自动变为 Done。
- **卡片排序。** 点击 Rearrange 拖动调整显示顺序，也可使用上下箭头。
- **简洁小窗口。** 一眼查看卡片数量、本季度待用权益，以及年费与已完成权益金额的对比。
- **自定义卡片名称。** 同一卡种可添加多张卡片，设置昵称，并用可选的后四位或后五位尾号区分。
- **只追踪需要的权益。** 隐藏不使用的权益，随时恢复，也可添加自定义卡片和权益。持卡年度报销或房券无需填日期即可记录；如需到期提醒，可选填银行显示的实际有效期。
- **内置卡片目录。** 提供 49 款可选产品，覆盖 American Express、Chase、Capital One、Citi、Bank of America、Bilt 和 Wells Fargo，并附带本地保存的官方卡面，无需实时银行 API。
- **深浅主题。** 以黑白灰为主，蓝色突出完成状态，也支持跟随系统主题。
- **中英文切换。** 默认英语，可在扩展内切换中文。
- **Chrome 同步。** 多台电脑的 Chrome 登录同一 Google 账号，并启用相关同步设置后，可以同步记录和偏好。

本季度计数包括从今天起至季度结束到期、尚未完成且未隐藏的权益周期。金额进度按实际记录金额计算；未记录金额的一键完成按完整周期额度估算，不代表银行确认的到账或实际利润。房券和积分不自动折算现金；资格、登记要求及有效期请以银行条款为准。

## 本地安装

Perk Done 已在 Chrome 商店上架。开发或提前试用新版时，可以自行构建，或使用维护者提供的已解压安装包。

1. 在电脑 Chrome 打开 `chrome://extensions`，开启右上角的**开发者模式**。
2. 点击**加载已解压的扩展程序**，选择直接包含 `manifest.json` 的文件夹。自行构建时选 `dist`；收到 ZIP 时，先解压，再选解压后的文件夹。
3. 将 **Perk Done** 固定到工具栏。点击图标打开小窗口，再点击**打开完整面板**查看年度时间表。

保留安装文件夹的位置。更新本地版时，覆盖原文件，再在扩展管理页点击**刷新**。卸载重装可能删除记录。本地版与商店版可能有不同的扩展 ID，记录不会自动跨这些身份迁移。

## 开发

使用 Node.js 24 或更新版本：

```sh
npm ci
npm run dev      # 浏览器开发预览
npm test         # 模型、存储、迁移、截止日期和目录检查
npm run build    # 生成 dist，用于加载已解压的扩展
npm run package  # 在 release 中生成带版本号的 ZIP
```

完整面板预览地址是 `http://127.0.0.1:5173/`，小窗口地址是 `http://127.0.0.1:5173/popup.html`。添加 `?demo=1` 可查看示例记录。网页预览使用独立的本地钱包，示例记录不保存。安装后的扩展无需运行开发服务器。

目录字段、截止日期规则、金额计算、存储细节和真实扩展浏览器检查见[开发说明（英文）](docs/development.md)。产品来源和核验日期见[目录核验记录](docs/catalog-review.md)。修改目录时，请保持已有产品和权益 ID 稳定。

## 隐私

只申请 `storage` 权限，不连接银行、不读取浏览历史、不包含分析组件，也没有开发者自建的钱包服务器。钱包使用 `chrome.storage.sync` 保存，启用同步后由 Google 处理跨设备同步；未启用时，记录留在当前设备。

Chrome Sync 为每个扩展提供约 100 KB 容量，单项上限为 8 KB。应用在写入前检查额度。多设备同时编辑可能相互覆盖，卸载可能删除数据；重要记录请独立备份。

保存字段及用户主动发送反馈邮件的处理方式见[隐私政策](PRIVACY.md)。
